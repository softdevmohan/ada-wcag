Loading State Rules

  • Always provide aria-busy="true" on the updating container while an asynchronous operation is in flight.
  • Include accessible text for screen readers (e.g. .sr-only) inside a role="status" container.
  • Respect prefers-reduced-motion by pausing continuous rotation for sensitive users.
