# ADA / WCAG Developer Code Templates

Angular 19 application with accessible, reusable WCAG 2.2 AA code templates.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:4200/`.

## Sidebar templates

The sidebar includes every original template category, including:

- **Dropdown / ng-select** — uses `@ng-select/ng-select`
- **Angular Material** — uses `@angular/material` and `@angular/cdk`
- Icons — uses `lucide` and `@lucide/angular`

## Scripts

- `npm start` — development server
- `npm run build` — production build
